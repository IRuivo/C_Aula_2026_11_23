Projeto de Matrizes e Strings em C
Sobre o projeto

Este projeto foi desenvolvido para praticar conceitos básicos da linguagem C, utilizando matrizes, strings e operações matemáticas.

#Conteúdos estudados
Criação e utilização de matrizes.
Declaração e manipulação de strings.
Soma dos elementos de cada linha da matriz.
Soma dos elementos de cada coluna da matriz.
Utilização de estruturas de repetição (for).
